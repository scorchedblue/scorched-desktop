# scorched-desktop

The desktop identity for ScorchedBlue: Hyprland's configuration and the
Quickshell shell.

Split from the OS image deliberately. This is user configuration — it lives in
`$HOME`, is deployed by chezmoi, and changes without rebuilding or rebooting
anything. `scorchedblue` ships the compositor and the shell *runtime*; this
decides how they behave and look.

## Layout

```
hypr/        Hyprland configuration (Lua)
quickshell/  the shell: bar, launcher, notifications  (not yet started)
```

## Hyprland 0.56 uses Lua

Not the older `hyprland.conf` format. This matters more than it sounds: nearly
every Hyprland config, tutorial and community dotfile you will find is the old
format and will not work here. Use the [wiki](https://wiki.hypr.land) rather
than copying configs.

The API is `hl.config({...})`, `hl.bind(...)`, `hl.exec_cmd(...)`,
`hl.window_rule({...})`, `hl.monitor({...})` and friends.

## Development loop

Configuration lives in `$HOME`, so testing needs no image rebuild.

```
just check   # syntax-check the Lua
just sync    # rsync into a running VM and hyprctl reload
```

The VM needs ssh forwarded. Boot it with `-netdev user,hostfwd=tcp::2222-:22`
and an ssh key added through `bootc-image-builder`'s `[[customizations.user]]`.

## Why the autogenerated config is not enough

Hyprland writes a default `~/.config/hypr/hyprland.lua` on first launch and
shows a warning banner over the desktop until it is replaced. That default
binds `SUPER+Q` to `kitty` and `SUPER+E` to `dolphin` — **neither is shipped by
ScorchedBlue**, which ships `ghostty`. So a fresh session greets you with a nag
banner and two keybindings that do nothing.

Only bind programs the image actually ships; a binding to something absent
fails silently.

## Keyboard

Terminal-first means keyboard-first, so every bar popout -- network,
Bluetooth, audio, displays, system stats, notifications, calendar, session --
opens, navigates and closes without a mouse:

| Popout        | Opens with        |
| ------------- | ------------------ |
| Network       | `SUPER+SHIFT+N`     |
| Bluetooth     | `SUPER+SHIFT+B`     |
| Audio         | `SUPER+SHIFT+A`     |
| Displays      | `SUPER+SHIFT+O`     |
| System stats  | `SUPER+SHIFT+T`     |
| Notifications | `SUPER+SHIFT+I`     |
| Calendar      | `SUPER+SHIFT+K`     |
| Session       | `SUPER+SHIFT+X`     |

Once one is open: `Down`/`Up` move the cursor through it, `Enter` or `Space`
activates whatever it is on, `Left`/`Right` adjust a volume slider, and
`Escape` closes it. The same keys work whether the popout was opened with a
click or a keybinding. See `hypr/hyprland.lua` for the bindings themselves and
`quickshell/Popouts.qml` for how a popout tracks the keyboard cursor.

## Stand-ins

`mako` (notifications) and `fuzzel` (launcher) are placeholders, autostarted
from the Hyprland config. The Quickshell shell replaces both. Remove them from
autostart when it does, or two notification daemons will race.
